# Task Manager API — Eulerity Backend Intern Assessment

A Spring Boot REST API for personal task management, featuring full CRUD operations and AI-powered endpoints backed by Claude (Anthropic).

---

## Quick Start (Single Command)

```bash
./mvnw spring-boot:run
```

Then open **http://localhost:8080** in your browser to use the UI.

> **Java 17** is required. Maven wrapper is included — no separate Maven installation needed.

---

## Setup Instructions

### 1. Clone the repository

```bash
git clone <your-repo-url>
cd taskmanager
```

### 2. (Optional) Add your Claude API key

The AI-powered endpoints work **without** an API key — they return realistic mock responses. To use real Claude responses, set the environment variable before running:

```bash
export CLAUDE_API_KEY=sk-ant-...
./mvnw spring-boot:run
```

Or add it directly to `src/main/resources/application.properties`:

```properties
claude.api.key=sk-ant-...
```

### 3. Run the project

```bash
./mvnw spring-boot:run
```

The server starts on `http://localhost:8080`.

### 4. Run the tests

```bash
./mvnw test
```

## API Reference

### Task CRUD

| Method | Path | Description |
|--------|------|-------------|
| `POST` | `/tasks` | Create a new task |
| `GET` | `/tasks` | List all tasks |
| `GET` | `/tasks/{id}` | Get a single task by ID |
| `PUT` | `/tasks/{id}` | Update a task |
| `DELETE` | `/tasks/{id}` | Delete a task |

**Task fields:**

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `title` | string | ✅ | |
| `description` | string | ❌ | |
| `dueDate` | date (YYYY-MM-DD) | ❌ | |
| `priority` | LOW / MEDIUM / HIGH | ❌ | Default: MEDIUM |
| `status` | TODO / IN_PROGRESS / DONE | ❌ | Default: TODO |

**Example — Create a task:**

```bash
curl -X POST http://localhost:8080/tasks \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Submit quarterly report",
    "description": "Finance team requires Q3 numbers by EOD Friday.",
    "dueDate": "2025-09-26",
    "priority": "HIGH",
    "status": "TODO"
  }'
```

### AI-Powered Endpoints

#### `POST /tasks/suggest`

Accepts a plain-language description and returns a structured task object parsed by Claude.

**Request:**
```json
{
  "description": "remind me to submit the quarterly report before Friday"
}
```

**Response:**
```json
{
  "title": "Submit Quarterly Report",
  "description": "Prepare and submit the quarterly financial report before the Friday deadline.",
  "dueDate": "2025-09-26",
  "priority": "HIGH",
  "status": "TODO"
}
```

**curl example:**
```bash
curl -X POST http://localhost:8080/tasks/suggest \
  -H "Content-Type: application/json" \
  -d '{"description": "remind me to submit the quarterly report before Friday"}'
```

---

#### `POST /tasks/{id}/breakdown`

Returns a list of suggested subtasks for a given task, generated by Claude.

**Response:**
```json
{
  "taskId": 1,
  "parentTask": "Submit quarterly report",
  "subtasks": [
    {
      "title": "Gather Q3 financial data",
      "description": "Pull all revenue and expense figures from the accounting system.",
      "priority": "HIGH"
    },
    {
      "title": "Draft executive summary",
      "description": "Write the 1-page summary for leadership review.",
      "priority": "MEDIUM"
    },
    {
      "title": "Review and proof",
      "description": "Check numbers, formatting, and grammar.",
      "priority": "MEDIUM"
    },
    {
      "title": "Submit to finance team",
      "description": "Email the finalized report to the finance team distribution list.",
      "priority": "LOW"
    }
  ]
}
```

**curl example:**
```bash
curl -X POST http://localhost:8080/tasks/1/breakdown
```

## Design Decisions

- **DTOs instead of exposing entities directly** — keeps the API contract decoupled from the persistence layer
- **Mock fallback in ClaudeAiService** — the app works without an API key so reviewers can run it cold
- **`@DirtiesContext` on integration tests** — ensures H2 is reset between tests for isolation
- **`@CrossOrigin("*")` on the controller** — simplifies running the frontend from any origin during development
